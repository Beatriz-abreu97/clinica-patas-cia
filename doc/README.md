# Documentos de apoio

Pasta para materiais que **não fazem parte do código** da solução: enunciado da disciplina, rascunhos e capturas de tela usadas no PDF de entrega.

Os PDFs desta pasta são ignorados pelo Git (ver `.gitignore`) para não versionar material de terceiros nem o arquivo final de entrega. As capturas de tela ficam em `doc/evidencias/` e são versionadas, porque servem de referência para o PDF.
